# Why is the C language called a structured language? Provide some practical questions explaining the concept

1.  Modular Programming Using Functions
    1.  A large program is broken into smaller, manageable functions.
    2.  Each function performs a specific task which improves reusability and readability.
2.  Control Structures
    1.  C executes the statements in the sequence order.
    2.  C filters controls the data flow using if, else, else-if, switch statements
    3.  It iterates the same instruction or data using the for, while, and do-while loops
3.  Emphasizes top-to-bottom approach
    1.  Breaking the problem into major components
    2.  Refining each component into smaller subcomponents
    3.  Continue this process until every part is simple enough to implement
4.  Better Maintainability
    1.  Readable blocks of code (like { }) clearly define scopes
    2.  Easier debugging because logic is predictable and structured
