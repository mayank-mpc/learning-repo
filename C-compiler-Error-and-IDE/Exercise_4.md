# What is a cross compiler?

1. A cross-compiler is a compiler that generates executable code for a platform other than the one on which the compiler is running.
   1. Example: if a compiler runs on a Linux machine and produces executable code for Windows, then it is a cross-compiler.
2. Cross compilers are typically used in embedded systems or when targeting platforms that are not available on the host machine.
3. They can optimize code for a specific platform, even if the development environment is different.
