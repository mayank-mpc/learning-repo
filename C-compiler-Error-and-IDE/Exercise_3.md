# What is a native compiler?

1. Native compilers generate code for the same platform on which they run.
2. It converts high-level language into the computer's native language.
   1. Example: Turbo C or GCC compiler
   2. Example: if a compiler runs on a Windows machine and produces executable code for Windows, it is a native compiler
3. Native compilers are widely used because they can optimize code for the specific processor and operating system of the host machine, resulting in faster and more efficient code execution.
