# What are opcodes in the assembler?

1.  In the assembler stage of C compilation, opcodes are the binary or symbolic operation codes that represent the actual instructions understood by the CPU.
2.  The assembler takes human-readable assembly instructions and converts them into machine instructions.
3.  Machine instruction has two parts:
    1.  Opcode (Operation Code) tells the CPU what operation to perform.
    2.  Operands are the data or values that an instruction operates on.
4.  CPU only understands machine code, and an opcode is a part of it.
