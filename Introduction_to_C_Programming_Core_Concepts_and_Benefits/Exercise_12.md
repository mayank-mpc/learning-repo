# Why is C general purpose language?

1. Versatality
   1. It was used to develop to the Windows OS, Linux, macOS.
   2. It was also used to develop high level languages like Python, C++, Java,etc
   3. It was used to develop the compilers and interpreters.
   4. Mostly used to develop the firmware for Microcontrollers and Iot embedded systems

2. Portability
   1. C programs can run on most of the machines with little or no changes.

3. Features
   1. It provides functionality of both high level and low level languages

# Why is C called procedural language?

1. The C programs executes as per the sequence of instructions
2. The C program also has functions which acts as a procedure which performs tasks ranging from small to very complex.
3. The flow of the complete program can be defined using the all the available C functionalities.

# Why C language supports low level memory access?

1. Pointer in C allows the program to read and write on specific memory addresses. Also, it allows the program to access the hardware registers for reading and writing data on the hardware registers.
2. Pointer arithmetic in C allows the program to seamlessly switch between different addresses in both memory and hardware registers.
3. Using malloc(), calloc(), realloc(), and free() the program can control the memory explicitly.
4. It also allows us to access the hardware registers directly.
5. It provides unrestricted memory access but it can also cause memory corruptions if unwanted read and write operations on the memory.

# Why C language has fast execution speed compared to other languages?

1. C programs has access to the low-level memory and it works closer to the hardware.
2. C program is directly compiled as machine level code which gives it added advantage and faster execution compared to other languages.

# Why is C language is called modular in feature?

1. C program can be broken down into smaller segments using the functions.
2. The functions can be reused in multiple places using the header files.
3. If functionalities are isolated in the C program it makes it easy to debug and understand.
4. Each source and header file can be compiled separately and can linked together afterwards as well.
