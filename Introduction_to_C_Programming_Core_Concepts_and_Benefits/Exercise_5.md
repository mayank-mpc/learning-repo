# What are the applications of the C language?

1. It is used to develop core components of operating systems such as Windows, Linux, and macOS.
2. It is used to program embedded systems in small devices.
3. It is used to construct compilers and interpreters such as GCC, Clang, TinyCC, CPython, Java Virtual Machine, Bash Shell.
4. It is used to create programs for devices and sensors of the Internet of Things (IoT).
5. It is used for creating lightweight and speedy desktop applications. The widely used text editor Notepad++ employs C for performance-sensitive sections.
6. It is also used in the field of medical sciences, automotive and mobile devices.
