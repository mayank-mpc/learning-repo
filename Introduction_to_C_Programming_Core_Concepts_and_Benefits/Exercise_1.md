# What is the C language?

C is a procedural programming language.

1. Initially developed by Dennis Ritchie in 1972 at Bell Laboratories of AT&T Labs.
2. It was mainly developed as a system programming language to write an operating system.
3. It is also used to write software that is fast, portable, and close to the hardware.
4. It is widely used for system programming, embedded systems, operating systems, and performance-critical applications.
