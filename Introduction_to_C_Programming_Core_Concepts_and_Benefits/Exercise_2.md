# What are the reasons to learn the C language?

1. It is considered the mother of all programming languages.
2. It helps you understand what’s happening behind the scenes in the hardware, as it works very closely with the hardware.
3. It is widely used in operating systems, embedded systems, compilers, databases, networking, game engines, and real-time systems for its efficiency to work in low-resource environments and hardware-level support.
4. It helps in building a base before learning any modern programming language, as it provides a deeper understanding of the fundamentals of programming.
5. It also helps in understanding the underlying architecture of the operating system, like pointers, working with memory locations, etc.
6. All the microcontroller SDKs (ESP-IDF, STM32 HAL, Zephyr RTOS, FreeRTOS, NRF SDK) are written in the C programming language.
