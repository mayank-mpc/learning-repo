# What is the history of the C programming language?

1. It was created by Dennis Ritchie in 1972 in Bell Laboratories of AT&T Labs, and he began programming in C, as an effort to make UNIX both more portable and more functional.
2. It was developed to overcome the limitations of languages like B and BCPL. These languages had no real data typing capability, and their structured programming was on the primitive side.
3. By 1973, the UNIX operating system was virtually rewritten in C, and we had complete system programming working in C.
4. As C gained popularity, variations emerged across different compilers and platforms, necessitating standardization.
