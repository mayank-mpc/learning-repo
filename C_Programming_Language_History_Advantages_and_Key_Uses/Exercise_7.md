# Which programming languages were used for system programming before the C language?

1.  Assembly Language
    1.  It is a low-level language that helps to communicate directly with computer hardware.
    2.  It uses mnemonics to represent the operations that a processor has to do.
    3.  It provided direct hardware control using CPU instructions.
    4.  It provides precise control over hardware and hence increased code optimization.
    5.  It is essential for making the operating systems, kernel, and device controllers that require hardware interaction for their functionality.
    6.  It is highly machine-dependent. So, it limits portability.
    7.  It is really hard to maintain the code, especially for large-scale projects, and debugging is also very challenging for programmers.
2.  BCPL
    1.  BCPL (Basic Combined Programming Language) is a foundational procedural programming language known for its simplicity and low-level capabilities.
    2.  It features concise syntax, manual memory management, and direct hardware interaction, making it historically significant in the evolution of programming languages and system programming.
    3.  Its simplicity allows developers to write efficient code that directly interacts with the hardware, crucial for tasks like writing operating systems and device drivers.
    4.  BCPL lacks the automatic memory management seen in modern languages, making it crucial for developers to manage memory allocation and deallocation directly within their code.
3.  Fortran
    1.  Fortran is a computer programming language that is extensively used in numerical, scientific computing.
    2.  Fortran programs can be highly optimised to run on high-performance computers, and in general the language is suited to producing code where performance is important.
    3.  Fortran is a compiled language, or more specifically, it is compiled ahead-of-time, in other words, you must perform a special step called compilation of your written code before running it on a computer.
    4.  Some early IBM operating system components used FORTRAN for non-critical subsystems.
4.  ALGOL
    1.  It is a high-level programming language that was developed in the late 1950s. It was designed for scientific and engineering computations and is considered one of the earliest and most influential programming languages.
    2.  It introduced structured programming concepts, making code easier to read and understand.
    3.  It introduced the concept of a block structure, allowing the grouping of statements into blocks.
    4.  Algol was one of the first languages to use strong typing, which means that variable types had to be explicitly defined. This feature enhanced program reliability.
    5.  Algol's concepts and syntax significantly influenced the design of subsequent programming languages, including Pascal, C, and Java.
5.  Pascal
    1.  Pascal is an ALGOL-based language, which includes features such as the ability to define data types and structures, its linear-type structure, and its imperative syntax.
    2.  It includes a strong type-checking system, which helps reduce errors during development and procedures & functions.

There were even more, but listed down mostly used languages for system programming.
