# What is a portable operating system?

1.  A **Portable OS** is an operating system that can be installed on a USB drive, CD/DVD, or other removable media and run directly from that media without being installed on the host computer.
2.  A portable OS is highly convenient for travelers, students, or professionals who frequently switch devices.
