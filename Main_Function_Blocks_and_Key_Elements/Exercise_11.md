# How can I tell if the C program executed successfully without errors?

1.  The program returns 0 when it gets executed successfully in the main function.
2.  Before execution, there is a compilation stage where the program is converted into machine code, but if there are any problems in the written code, then the program cannot be executed at all.
3.  To run the code successfully, the compilation has to be error and warning-free. Also, the program needs to return 0 to signify the successful execution of the error.
